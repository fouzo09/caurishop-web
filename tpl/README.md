# CAURISHOP — Template e-commerce (HTML + CSS + Bootstrap 5)

Template statique complet d'une marketplace, prêt à être intégré dans Laravel (Blade).

## Structure
- `index.html` — Accueil (bannière promo carrousel, catégories, meilleures ventes, nouveautés)
- `boutique.html` — Listing produits (filtres, tri, pagination)
- `produit.html` — Fiche produit (galerie, variantes, onglets, suggestions)
- `panier.html` — Panier (quantités et totaux dynamiques)
- `checkout.html` — Paiement & livraison (3 étapes, moyens de paiement guinéens)
- `confirmation.html` — Confirmation de commande (suivi)
- `compte.html` — Connexion / Inscription
- `contact.html` — À propos & contact
- `assets/css/style.css` — Charte CAURISHOP par-dessus Bootstrap
- `assets/js/main.js` — Interactions (panier, galerie, checkout, filtres)

## Dépendances (CDN)
- Bootstrap 5.3.3 (CSS + JS bundle)
- Google Fonts : DM Sans

Ouvrir simplement `index.html` dans un navigateur — aucune installation requise.
